# Simulador de llaves de torneos de Jiu-Jitsu

Simulador de llaves de torneo de BJJ con categorías según la IBJJF (adultos y masters, con kimono).

## Requisitos

- Java 21 o superior
- Maven

## Correr los tests

```bash
mvn test
```
